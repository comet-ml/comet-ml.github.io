# Comet Open Source Repositories

This page lists the open source repositories from <a
href="https://www.comet.com/">Comet</a>. Please feel free to make
comments, ask questions, or make pull requests.


* <a href="https://github.com/comet-ml/opik/">opik</a> - Debug, evaluate, and monitor your LLM applications, RAG systems, and agentic workflows
* <a href="https://github.com/comet-ml/opik-mcp/">opik-mcp</a> - Model Context Protocol (MCP) server for Opik
* <a href="https://github.com/comet-ml/opik-claude-code-plugin/">opik-claude-code-plugin</a> - Log Claude Code sessions to Opik
* <a href="https://github.com/comet-ml/opik-openclaw/">opik-openclaw</a> - OpenClaw plugin that exports agent traces to Opik
* <a href="https://github.com/comet-ml/kangas/">kangas</a> - Explore multimedia datasets at scale
* <a href="https://github.com/comet-ml/comet-examples/">comet-examples</a> - Examples of Machine Learning code using Comet
* <a href="https://github.com/comet-ml/cometx/">cometx</a> - Open source contributions for integrations with comet_ml
* <a href="https://github.com/comet-ml/cometr/">cometr</a> - Comet SDK for the R programming language
* <a href="https://github.com/comet-ml/comet-for-mlflow/">comet-for-mlflow</a> - Comet-For-MLFlow Extension
* <a href="https://github.com/comet-ml/comet-ml.github.io/">comet-ml.github.io</a> - JavaScript libraries for creating custom visualizations using <a href="https://www.comet.com/docs/v2/guides/comet-ui/experiment-management/visualizations/comet-panels/">Comet Panels</a>
