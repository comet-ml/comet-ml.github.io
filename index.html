Comet Open Source Repositories

This page lists the open source repositories from Comet. Please feel free to make comments, ask questions, or make pull requests.

  • opik - Debug, evaluate, and monitor your LLM applications, RAG systems, and agentic workflows
  • opik-mcp - Model Context Protocol (MCP) server for Opik
  • opik-claude-code-plugin - Log Claude Code sessions to Opik
  • opik-openclaw - OpenClaw plugin that exports agent traces to Opik
  • kangas - Explore multimedia datasets at scale
  • comet-examples - Examples of Machine Learning code using Comet
  • cometx - Open source contributions for integrations with comet_ml
  • cometr - Comet SDK for the R programming language
  • comet-for-mlflow - Comet-For-MLFlow Extension
  • comet-ml.github.io - JavaScript libraries for creating custom visualizations using Comet Panels
